# Data Files

This folder contains the processed input profiles required by
`main_intervalrobust.m`.

Required files:

- `temperatureforuncertaintyset1.mat`: temperature residual samples.
- `temperature_ontime.mat`: forecasted outdoor-temperature profile.
- `humidity_24h.mat`: forecasted relative-humidity profile.
- `pressure_24h.mat`: forecasted air-pressure profile.
- `humidity_ontime.mat`: relative-humidity residual samples.
- `pressure_ontime.mat`: air-pressure residual samples.
- `windpower_24h.mat`: forecasted renewable-energy profile.
- `windpowerforuncertaintyset.mat`: renewable-energy residual samples.
- `realtimeworkload_forecast_tencent.mat`: real-time workload profile.

The files are processed numerical inputs for the example case.
